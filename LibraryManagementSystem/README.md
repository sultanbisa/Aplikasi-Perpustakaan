# Library Management System

Aplikasi Manajemen Perpustakaan berbasis
Python dan SQLite.

## Deskripsi

Library Management System merupakan aplikasi
sederhana untuk membantu pengelolaan
perpustakaan melalui Terminal atau CMD.

## Fitur

- Menambahkan data buku
- Menampilkan daftar buku
- Mencari buku
- Menghapus buku
- Menambahkan anggota
- Menampilkan data anggota
- Mencari anggota
- Menghapus anggota
- Peminjaman buku
- Pengembalian buku
- Riwayat peminjaman
- Dashboard statistik

## Teknologi

- Python
- SQLite
- Visual Studio Code

## Cara Menjalankan

1. Install Python.
2. Buka folder proyek di VS Code.
3. Buka terminal.
4. Jalankan perintah:

   python main.py

## Database

Aplikasi menggunakan SQLite untuk
menyimpan data buku, anggota,
dan transaksi peminjaman.
